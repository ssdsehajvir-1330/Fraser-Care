# Waitlist Management — Initial Plan

## Overview
The waitlist management system will allow customers to join a waitlist when pharmacy appointment slots are full.

## Planned Functionality
- Allow customers to join a waitlist for unavailable appointments.
- Allow customers to view their waitlist status.
- Allow pharmacy staff to view and manage the waitlist.
- Handle newly available appointment slots for cancelled appointments.

## Dependencies
- Appointment Booking: Requires communication with the booking system to identify available slots.
- User Authentication: Requires customer accounts to identify waitlist entries.
- Staff Dashboard: Requires integration so staff can manage the waitlist.

## Next Steps
- Discuss appointment and waitlist database structure with the appointment booking developer.
- Determine how waitlist entries will be stored and define how cancelled appointments affect waitlists.
- Begin implementation after agreement.
